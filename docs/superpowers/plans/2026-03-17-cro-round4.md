# Round 4: CRO Improvements Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix 6 conversion issues: replace fake social proof, reduce hero CTAs, add founding member email capture with urgency pricing, add pricing plan labels with price anchoring, make the flame graph demo interactive, and add a video placeholder.

**Architecture:** New components (CredibilityStrip, FoundingMemberCta, VideoEmbed) plus modifications to existing ones (TrustBar, Pricing, FlameDemo). Email capture uses Lemon Squeezy audience API with localStorage for shared state across capture points. FlameDemo gets data attributes on spans for tooltip/detail-panel interactivity.

**Tech Stack:** Astro, TypeScript, CSS, client-side JavaScript (fetch for API, localStorage for state)

**Spec:** `docs/superpowers/specs/2026-03-17-cro-round4-design.md`

### Task 6: FlameDemo interactivity

**Files:**
- Modify: `src/components/FlameDemo.astro`

- [ ] **Step 1: Update span data type and add AI insights**

Update the `spanData` type to include optional `ai` field:

```ts
Array<{ d: number; n: string; t: string; s: number; w: number; ai?: string }>
```

Add `ai` strings to 3 key spans per variant:

**default:** WC transient check, Elementor CSS, oEmbed HTTP
**woocommerce:** License check, DB: related query, Stripe API
**elementor:** DB: _elementor_data, 12 widget renders, 18 CSS enqueues
**agency:** License checks (x3), DB: ACF meta, Analytics API

Each `ai` value is a one-line recommendation (e.g., "This license check runs on every request — switch to wp-cron scheduling").

- [ ] **Step 2: Add data attributes to span rendering**

In the span creation loop, add `dataset` properties:
- `el.dataset.name = s.n`
- `el.dataset.duration` = duration in ms
- `el.dataset.percent` = percentage of total
- `el.dataset.type = s.t`
- `el.dataset.ai = s.ai` (when present)
- `el.style.cursor = 'pointer'`

- [ ] **Step 3: Add tooltip and detail panel HTML**

Before the `.demo-ai` section, add:
- A `.flame-tooltip` div (fixed positioned, hidden by default)
- A `.demo-detail-panel` div with close button, name/meta/AI content areas

- [ ] **Step 4: Add tooltip and detail panel CSS**

Tooltip: fixed position, dark background (`--carbon-700`), monospace font, shadow, hidden by default.
Detail panel: subtle card below flame graph, animated entrance, close button top-right, AI insight line with `✦` prefix in `--ai-300`.

- [ ] **Step 5: Add tooltip and detail panel JavaScript**

At the end of the existing script, add event listeners for all `.f-block` elements:
- `mouseenter`: show tooltip with span name, duration, percent
- `mousemove`: position tooltip near cursor
- `mouseleave`: hide tooltip
- `click`: populate detail panel from data attributes, show panel, smooth scroll into view
- Close button: hide detail panel

Use `textContent` (not innerHTML) when setting content from data attributes to avoid XSS.

- [ ] **Step 6: Build and verify**

Run: `bun run build`
Expected: Build passes.
